# Roadmap

## Near-term (Next 1-2 iterations)
- Add centralized CMS-like content configuration (JSON/MD-based) for easier non-dev edits.
- Improve micro-animations (section reveal, card transitions) with reduced-motion support.
- Strengthen form validation UX (field-level messages, error summaries, submit throttling).
- Add reusable section primitives for faster landing-page variants.

## Mid-term
- Add multilingual UI switcher (manual language control) and URL-based locale support.
- Integrate privacy-friendly analytics (for example Plausible/self-hosted alternatives).
- Add Lighthouse performance/accessibility CI checks.
- Improve image/video optimization strategy (responsive formats, compression pipeline).

## Longer-term
- Introduce structured content schema for multiple products/use-cases.
- Expand component library with consistent design tokens and patterns.
- Add richer SEO assets (dynamic OG images per locale/variant).
- Add visual regression testing for responsive layouts.

## Targeted Improvements Requested
- CMS/content config enhancement
- Better motion/animation polish
- Multilingual support expansion
- Privacy-friendly analytics integration
- Stronger form validation
- Automated accessibility checks
- Higher Lighthouse score targets
- More reusable components
